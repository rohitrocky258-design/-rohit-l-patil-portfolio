# Rohit L Patil — Professional Portfolio

## Files
- `index.html` — main portfolio page
- `style.css` — responsive styling
- `script.js` — mobile navigation and dynamic footer year

## How to run
1. Extract the ZIP.
2. Open `index.html` in any modern browser.

## Customize
Edit `index.html` to add:
- Your college name
- LinkedIn profile
- GitHub profile
- Project GitHub/demo links
- Resume PDF
- More projects/certifications

No build tools are required.
